# خادم الترخيص المرجعي — اختياري

التطبيق والترخيص يعملان بلا أي خادم. الخادم يضيف أمرين فقط:
1. **قائمة الإلغاء:** الهاتف المفقود أو الرخصة المنقولة تُلغى على الهاتف القديم عند أول فحص (كل 7 أيام، حين يتصل الهاتف).
2. **أسعار الصرف التي تحددها أنت** (مثل أسعار السوق المحلية) بدل المصدر العالمي.

## التشغيل
- يحتاج Node.js 18 أو أحدث فقط (لا مكتبات). على خادم VPS:
  ```
  PORT=8080 node server.js
  ```
- 10.11: خلف Caddy أو nginx أضف `TRUST_PROXY=1` ليُحسب حد الطلبات بعنوان العميل الحقيقي؛ والرد على الفحص يحمل رخصة الطالب وحدها إن كانت ملغاة (لا القائمة كلها).
- ضعه خلف HTTPS (التطبيق لا يقبل إلا https). أسهل طريقة Caddy:
  ```
  license.example.com {
      reverse_proxy 127.0.0.1:8080
  }
  ```
- في التطبيق: المزيد ← الترخيص ← «خادم الترخيص» ← اكتب `https://license.example.com` ← «حفظ العنوان».
- لأسعار الصرف: المزيد ← البيانات ← أسعار الصرف ← «تغيير مصدر الأسعار» ← `https://license.example.com/v1/rates`.

## البيانات (مجلد `data/`)
- `licenses.json`: من أداة البائع ← سجل المبيعات ← «تنزيل سجل الخادم». ارفعه بعد كل بيع أو نقل أو تسجيل فقد.
- `rates.json` (اختياري): `{"rates": {"USD": 1, "SYP": 13100, "TRY": 41.2}, "updatedAt": "2026-10-14T08:00:00Z"}` — عدد وحدات كل عملة مقابل الدولار.

## ما يصل الخادم وما لا يصل
- يصله: رقم الرخصة، وبصمة مفتاح الهاتف ومفتاحه العام، وتوقيع الهاتف على طلب الفحص (يثبت أنه الهاتف المسجّل). لا يصله أي اسم أو مبلغ أو حركة.
- لا يحمل المفتاح الخاص للبائع: لا يستطيع إصدار رخص، واختراقه لا يسمح بتزوير رمز.
- يرفض: التوقيع غير الصحيح، والطلب المعدَّل، والطلب المكرر، والطلب بساعة بعيدة أكثر من يومين، والطلبات الكثيرة (60 في الدقيقة لكل عنوان).
