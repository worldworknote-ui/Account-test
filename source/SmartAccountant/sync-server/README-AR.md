# خادم المزامنة الخاص — «المحاسب الذكي» 10.4

خادم صغير تملكه أنت، تمر عبره مزامنة أجهزتك (الهاتف والماك والويندوز). تصل التغييرات خلال ثوانٍ.

## ماذا يرى الخادم؟
لا شيء من حساباتك:
- يحفظ ملفات مشفّرة بأسماء معتمة كما تصله.
- مفتاح التشفير لا يغادر أجهزتك أبدًا.
- يحفظ لكل خزنة **بصمة** رمز الكتابة فقط. الرمز نفسه مشتق من مفتاح الخزنة، فلا يكتب فيها إلا أجهزتك.

## التشغيل
يحتاج Node.js 18 أو أحدث فقط، بلا أي مكتبات.

1. **على خادم VPS (لينكس):**
   ```
   SERVER_KEY='اكتب-هنا-رمزًا-طويلًا-عشوائيًا' PORT=8090 node server.js
   ```
   - `SERVER_KEY` (مستحسن جدًا): «رمز الخادم» الذي تكتبه في التطبيق. بدونه يستطيع أي أحد يعرف العنوان إنشاء خزنات على خادمك.
     لا يستطيع أحد قراءة خزنتك في الحالتين، لكن بدونه قد تمتلئ المساحة.
   - `DATA_DIR` (اختياري): مكان الملفات، والافتراضي `./vaults`. **خذ منه نسخة احتياطية دوريًا.**
   - `MAX_FILE_MB` (الافتراضي 64) و`MAX_VAULT_MB` (الافتراضي 2048): حدود الحجم.
   - `RATE_PER_MIN` (الافتراضي 1200): أكثر عدد طلبات في الدقيقة لكل عنوان IP.
   - `MAX_TOTAL_MB` (الافتراضي 20480): أكبر حجم لكل الخزنات معًا (10.11).
   - `TRUST_PROXY=1`: ضعه فقط إن كان الخادم خلف Caddy أو nginx، فيؤخذ عنوان العميل لحد الطلبات من آخر ما أضافه الوكيل في `X-Forwarded-For`. بدونه يُستعمل عنوان الاتصال نفسه (10.11).
   - الخادم يرفض البدء إن بقي `SERVER_KEY` على القيمة النموذجية `change-me…` من ملف الخدمة (10.11).
2. **ضعه خلف HTTPS**، لأن التطبيق لا يقبل إلا https. أسهل طريقة Caddy (يستخرج الشهادة وحده):
   ```
   sync.example.com {
       reverse_proxy 127.0.0.1:8090
   }
   ```
3. **ليعمل دائمًا** (systemd): انسخ `smart-accountant-sync.service` إلى `/etc/systemd/system/`، وعدّل فيه المسار و`SERVER_KEY`، ثم نفّذ:
   ```
   systemctl enable --now smart-accountant-sync
   ```

## في التطبيق
1. **على الجهاز الرئيسي** (الذي فيه بياناتك الكاملة):
   - «المزيد ← المزامنة ← خادم المزامنة الخاص بك».
   - اكتب `https://sync.example.com` ورمز الخادم ← «حفظ وفحص الاتصال».
   - «إنشاء المزامنة» ← كلمة سر المزامنة.
   - يظهر **رابط الانضمام**: انسخه.
2. **على كل جهاز آخر:** «المزامنة ← خادم المزامنة الخاص بك» ← الصق رابط الانضمام ورمز الخادم ← «حفظ وفحص الاتصال» ← «الانضمام» ← كلمة سر المزامنة.
3. **إن كانت أجهزتك تتزامن الآن بطريقة أخرى:** على كل جهاز «المزامنة ← الطريقة: تغيير ← خادم المزامنة الخاص بك».
   تُنقل الخزنة كما هي، بلا إعادة انضمام.

## الواجهة
| الطلب | الوظيفة |
|---|---|
| `GET /v1/health` | الحالة |
| `GET /v1/vault/<id>/list?prefix=` | قائمة الملفات (بالرمز) |
| `GET /v1/vault/<id>/file/<name>` | تنزيل ملف (الرأس بلا رمز: فيه الملح والمفتاح المغلّف بكلمة السر فقط) |
| `PUT /v1/vault/<id>/file/<name>` | رفع ملف (بالرمز؛ أول رفع يسجّل بصمته) |
| `DELETE /v1/vault/<id>/file/<name>` | 10.4: حذف ملف (بالرمز) — التطبيق يحذف الحزم القديمة بعد وصولها لكل الأجهزة |

## التحديث إلى 10.4
استبدل `server.js` بالنسخة الجديدة وأعد تشغيل الخدمة (`systemctl restart smart-accountant-sync`). الملفات المحفوظة تبقى كما هي.
الخادم الأقدم يعمل مع التطبيق 10.4، لكن التنظيف التلقائي لا يعمل عليه (تظهر رسالة «حدّث server.js»).
