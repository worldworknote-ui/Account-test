1: # خادم الترخيص المرجعي — اختياري
2: 
3: التطبيق والترخيص يعملان بلا أي خادم. الخادم يضيف أمرين فقط:
4: 1. **قائمة الإلغاء:** الهاتف المفقود أو الرخصة المنقولة تُلغى على الهاتف القديم عند أول فحص (كل 7 أيام، حين يتصل الهاتف).
5: 2. **أسعار الصرف التي تحددها أنت** (مثل أسعار السوق المحلية) بدل المصدر العالمي.
6: 
7: ## التشغيل
8: - يحتاج Node.js 18 أو أحدث فقط (لا مكتبات). على خادم VPS:
9:   ```
10:   PORT=8080 node server.js
11:   ```
12: - 10.11: خلف Caddy أو nginx أضف `TRUST_PROXY=1` ليُحسب حد الطلبات بعنوان العميل الحقيقي؛ والرد على الفحص يحمل رخصة الطالب وحدها إن كانت ملغاة (لا القائمة كلها).
13: - ضعه خلف HTTPS (التطبيق لا يقبل إلا https). أسهل طريقة Caddy:
14:   ```
15:   license.example.com {
16:       reverse_proxy 127.0.0.1:8080
17:   }
18:   ```
19: - في التطبيق: المزيد ← الترخيص ← «خادم الترخيص» ← اكتب `https://license.example.com` ← «حفظ العنوان».
20: - لأسعار الصرف: المزيد ← البيانات ← أسعار الصرف ← «تغيير مصدر الأسعار» ← `https://license.example.com/v1/rates`.
21: 
22: ## البيانات (مجلد `data/`)
23: - `licenses.json`: من أداة البائع ← سجل المبيعات ← «تنزيل سجل الخادم». ارفعه بعد كل بيع أو نقل أو تسجيل فقد.
24: - `rates.json` (اختياري): `{"rates": {"USD": 1, "SYP": 13100, "TRY": 41.2}, "updatedAt": "2026-10-14T08:00:00Z"}` — عدد وحدات كل عملة مقابل الدولار.
25: 
26: ## ما يصل الخادم وما لا يصل
27: - يصله: رقم الرخصة، وبصمة مفتاح الهاتف ومفتاحه العام، وتوقيع الهاتف على طلب الفحص (يثبت أنه الهاتف المسجّل). لا يصله أي اسم أو مبلغ أو حركة.
28: - لا يحمل المفتاح الخاص للبائع: لا يستطيع إصدار رخص، واختراقه لا يسمح بتزوير رمز.
29: - يرفض: التوقيع غير الصحيح، والطلب المعدَّل، والطلب المكرر، والطلب بساعة بعيدة أكثر من يومين، والطلبات الكثيرة (60 في الدقيقة لكل عنوان).
30: 
31: ## الاختبار
32: ```
33: node test/server.test.js
34: ```
