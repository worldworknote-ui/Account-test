1: # خادم المزامنة الخاص — «المحاسب الذكي» 10.4
2: 
3: خادم صغير تملكه أنت، تمر عبره مزامنة أجهزتك (الهاتف والماك والويندوز). تصل التغييرات خلال ثوانٍ.
4: 
5: ## ماذا يرى الخادم؟
6: لا شيء من حساباتك:
7: - يحفظ ملفات مشفّرة بأسماء معتمة كما تصله.
8: - مفتاح التشفير لا يغادر أجهزتك أبدًا.
9: - يحفظ لكل خزنة **بصمة** رمز الكتابة فقط. الرمز نفسه مشتق من مفتاح الخزنة، فلا يكتب فيها إلا أجهزتك.
10: 
11: ## التشغيل
12: يحتاج Node.js 18 أو أحدث فقط، بلا أي مكتبات.
13: 
14: 1. **على خادم VPS (لينكس):**
15:    ```
16:    SERVER_KEY='اكتب-هنا-رمزًا-طويلًا-عشوائيًا' PORT=8090 node server.js
17:    ```
18:    - `SERVER_KEY` (مستحسن جدًا): «رمز الخادم» الذي تكتبه في التطبيق. بدونه يستطيع أي أحد يعرف العنوان إنشاء خزنات على خادمك.
19:      لا يستطيع أحد قراءة خزنتك في الحالتين، لكن بدونه قد تمتلئ المساحة.
20:    - `DATA_DIR` (اختياري): مكان الملفات، والافتراضي `./vaults`. **خذ منه نسخة احتياطية دوريًا.**
21:    - `MAX_FILE_MB` (الافتراضي 64) و`MAX_VAULT_MB` (الافتراضي 2048): حدود الحجم.
22:    - `RATE_PER_MIN` (الافتراضي 1200): أكثر عدد طلبات في الدقيقة لكل عنوان IP.
23:    - `MAX_TOTAL_MB` (الافتراضي 20480): أكبر حجم لكل الخزنات معًا (10.11).
24:    - `TRUST_PROXY=1`: ضعه فقط إن كان الخادم خلف Caddy أو nginx، فيؤخذ عنوان العميل لحد الطلبات من آخر ما أضافه الوكيل في `X-Forwarded-For`. بدونه يُستعمل عنوان الاتصال نفسه (10.11).
25:    - الخادم يرفض البدء إن بقي `SERVER_KEY` على القيمة النموذجية `change-me…` من ملف الخدمة (10.11).
26: 2. **ضعه خلف HTTPS**، لأن التطبيق لا يقبل إلا https. أسهل طريقة Caddy (يستخرج الشهادة وحده):
27:    ```
28:    sync.example.com {
29:        reverse_proxy 127.0.0.1:8090
30:    }
31:    ```
32: 3. **ليعمل دائمًا** (systemd): انسخ `smart-accountant-sync.service` إلى `/etc/systemd/system/`، وعدّل فيه المسار و`SERVER_KEY`، ثم نفّذ:
33:    ```
34:    systemctl enable --now smart-accountant-sync
35:    ```
36: 
37: ## في التطبيق
38: 1. **على الجهاز الرئيسي** (الذي فيه بياناتك الكاملة):
39:    - «المزيد ← المزامنة ← خادم المزامنة الخاص بك».
40:    - اكتب `https://sync.example.com` ورمز الخادم ← «حفظ وفحص الاتصال».
41:    - «إنشاء المزامنة» ← كلمة سر المزامنة.
42:    - يظهر **رابط الانضمام**: انسخه.
43: 2. **على كل جهاز آخر:** «المزامنة ← خادم المزامنة الخاص بك» ← الصق رابط الانضمام ورمز الخادم ← «حفظ وفحص الاتصال» ← «الانضمام» ← كلمة سر المزامنة.
44: 3. **إن كانت أجهزتك تتزامن الآن بطريقة أخرى:** على كل جهاز «المزامنة ← الطريقة: تغيير ← خادم المزامنة الخاص بك».
45:    تُنقل الخزنة كما هي، بلا إعادة انضمام.
46: 
47: ## الواجهة
48: | الطلب | الوظيفة |
49: |---|---|
50: | `GET /v1/health` | الحالة |
51: | `GET /v1/vault/<id>/list?prefix=` | قائمة الملفات (بالرمز) |
52: | `GET /v1/vault/<id>/file/<name>` | تنزيل ملف (الرأس بلا رمز: فيه الملح والمفتاح المغلّف بكلمة السر فقط) |
53: | `PUT /v1/vault/<id>/file/<name>` | رفع ملف (بالرمز؛ أول رفع يسجّل بصمته) |
54: | `DELETE /v1/vault/<id>/file/<name>` | 10.4: حذف ملف (بالرمز) — التطبيق يحذف الحزم القديمة بعد وصولها لكل الأجهزة |
55: 
56: ## التحديث إلى 10.4
57: استبدل `server.js` بالنسخة الجديدة وأعد تشغيل الخدمة (`systemctl restart smart-accountant-sync`). الملفات المحفوظة تبقى كما هي.
58: الخادم الأقدم يعمل مع التطبيق 10.4، لكن التنظيف التلقائي لا يعمل عليه (تظهر رسالة «حدّث server.js»).
