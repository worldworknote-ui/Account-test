29:  * مهما كان مسار الكود. «الختم» يحوّل التغييرات المكتملة إلى حزمة: صورة كل صف كما هو الآن (مفكوك التشفير المحلي)، بساعة HLC.

31:  *
32:  * <p>قواعد الدقة المحاسبية:
33:  * <ul>
34:  *   <li>أرقام الصفوف عالمية: كل جهاز يرقّم من نطاقه (بادئته × 2^32)، فالصف نفسه بالرقم نفسه على كل الأجهزة، والأرصدة
35:  *       تُشتق دائمًا من مجموع سطور القيود (لا أرقام مخزّنة تُدمج).</li>
36:  *   <li>القيود تُضاف ولا تُعدَّل: الإلغاء قيد عكسي (REVERSAL) يشير إلى الأصل. إلغاء الحركة نفسها من جهازين = قيدان عكسيان
37:  *       للأصل نفسه؛ الثاني يُتجاهل عند الوصول (لا يُلغى المبلغ مرتين).</li>
38:  *   <li>تعديل الحركة نفسها من جهازين: الأسبق بالساعة يبقى، والأحدث يُلغيه الجهاز الذي أنشأه بقيد عكسي عادي، ويُسجَّل
39:  *       تعارضًا للمراجعة (لا دمج تلقائي للمبالغ).</li>
40:  *   <li>البيانات غير المالية (اسم مكتب، إعداد…) : الأحدث بالساعة يفوز للصف كله.</li>
41:  *   <li>صف يشير إلى صف حذفه جهاز آخر (مكتب محذوف مثلًا): لا يُطبَّق ويُسجَّل تعارضًا.</li>

105:     static String keyExpr(String alias, String[] key) {
106:         if (key.length == 1) return alias + "." + key[0];
107:         StringBuilder b = new StringBuilder();
108:         for (int i = 0; i < key.length; i++) {
109:             if (i > 0) b.append("||'|'||");
110:             b.append(alias).append('.').append(key[i]);
111:         }
112:         return b.toString();
113:     }

115:     static void ensureSchema(SQLiteDatabase d) {
116:         for (String s : DDL) d.execSQL(s);
117:         // 10.4: الصور التي تحتاجها كل حزمة (تُرفع قبلها)
118:         boolean hasBlobs = false;
119:         try (Cursor c = d.rawQuery("PRAGMA table_info(sync_outbox)", null)) {
120:             while (c.moveToNext()) if ("blobs".equals(c.getString(1))) hasBlobs = true;
121:         }
122:         if (!hasBlobs) d.execSQL("ALTER TABLE sync_outbox ADD COLUMN blobs TEXT");
123:         d.execSQL("INSERT OR IGNORE INTO sync_flag(id,cap) VALUES(1,0)");
124:         String cap = "(SELECT cap FROM sync_flag WHERE id=1)=1";
125:         for (String[] t : TABLES) {
126:             String name = t[0];
127:             String[] key = KEYS.get(name);
128:             String nw = keyExpr("NEW", key), od = keyExpr("OLD", key);
129:             if (name.equals("exchange_rates")) {
130:                 // أسعار الإنترنت يجلبها كل جهاز بنفسه؛ يُزامَن السعر اليدوي فقط
131:                 d.execSQL("CREATE TRIGGER IF NOT EXISTS sync1_i_" + name + " AFTER INSERT ON " + name + " WHEN " + cap + " AND NEW.manual_rate IS NOT NULL"
132:                         + " BEGIN INSERT INTO sync_chg(tbl,rid,op) VALUES('" + name + "'," + nw + ",'U'); END");
133:                 d.execSQL("CREATE TRIGGER IF NOT EXISTS sync1_u_" + name + " AFTER UPDATE OF manual_rate,manual_at ON " + name + " WHEN " + cap
134:                         + " BEGIN INSERT INTO sync_chg(tbl,rid,op) VALUES('" + name + "'," + nw + ",'U'); END");
135:                 continue;
136:             }
