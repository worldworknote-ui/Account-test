257:     /** التكرارات المحتملة المفتوحة؛ ما حُسم (أُلغيت إحداهما أو قيل «ليستا مكررتين» من أي جهاز) يُغلق تلقائيًا. */
258:     public static List<Dup> duplicates(Db db) {
259:         List<Dup> out = new ArrayList<>();
260:         SQLiteDatabase d = db.getWritableDatabase();
261:         List<Object[]> rows = new ArrayList<>();
262:         try (Cursor c = d.rawQuery("SELECT id,rid FROM sync_conflicts WHERE kind='DUPLICATE' AND resolved=0 ORDER BY created_at DESC LIMIT 200", null)) {
263:             while (c.moveToNext()) rows.add(new Object[]{c.getLong(0), c.getString(1)});
264:         }
265:         for (Object[] r : rows) {
266:             String[] p = ((String) r[1]).split("\\|");
267:             Dup x = new Dup();
268:             x.conflictId = (Long) r[0];
269:             try {
270:                 x.a = db.tx(Long.parseLong(p[0]));
271:                 x.b = db.tx(Long.parseLong(p[1]));
272:             } catch (Exception e) {
273:                 x.a = null;
274:             }
275:             boolean open = x.a != null && x.b != null && (x.a.isActive() || x.a.isPending()) && (x.b.isActive() || x.b.isPending())
276:                     && !SyncStore.dupOk(d, Math.min(x.a.id, x.b.id), Math.max(x.a.id, x.b.id));
277:             if (!open) d.execSQL("UPDATE sync_conflicts SET resolved=1 WHERE id=" + x.conflictId);
278:             else out.add(x);
279:         }
280:         return out;
281:     }
