20:  *
21:  * <p>الصندوق يضبط النقد الموجود فعلًا لدى صاحب المكتب بكل عملة، مستقلًا عن أرصدة المكاتب: حساباته في جدول خاص
22:  * (cash_moves) ولا تدخل دفتر قيود المكاتب. الربط الوحيد بالمكاتب حركة «استلام» أو «تسليم» لحساب مكتب:
23:  * تُسجَّل حركة عادية على المكتب (بقيودها) في المعاملة نفسها، ويُحفظ رقمها مع حركة الصندوق، فتتبع حالتها
24:  * (بانتظار الاعتماد أو مرفوضة = لا تُحسب في الصندوق، وإلغاؤها يلغي الأخرى).
25:  *

27:  * (لنا تدخل، علينا تخرج). أجور الحركة المرتبطة بمكتب تُقيَّد افتراضيًا على حساب المكتب (لا تمس النقد)
28:  * إلا إذا قُبضت أو دُفعت نقدًا. خلاصة أي فترة تحقق: آخر الفترة = أولها + الداخل − الخارج (يتحقق منه الاختبار).

108:         public long effect() { return counts() ? dir * amount + feeCash() : 0; }
