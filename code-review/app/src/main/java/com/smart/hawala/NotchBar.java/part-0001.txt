132:      * (تغوص في الشريط) ثم تصعد عند الوصول بارتداد خفيف — فتبدو كأنها تسبح إلى مكانها وتطفو للأعلى.
133:      */
134:     void slideTo(final int i) {
135:         if (anim != null) anim.cancel();
136:         target = i;
137:         lastPos = i;
138:         setContentDescription(names.get(i));
139:         if (Ui.NO_MOTION) {
140:             pos = i;
141:             lift = 1f;
142:             invalidate();
143:             return;
144:         }
145:         final float from = pos, fromLift = lift;
146:         final float dist = Math.abs(i - from);
147:         if (dist < 0.01f && lift > 0.99f) return;
148:         final float dip = Math.min(0.62f, 0.3f + 0.12f * dist);
149:         ValueAnimator a = ValueAnimator.ofFloat(0f, 1f);
150:         a.setDuration((long) (480 + 90 * Math.min(4f, dist)));
151:         a.setInterpolator(new android.view.animation.LinearInterpolator());
152:         final android.view.animation.Interpolator move = new android.view.animation.PathInterpolator(0.45f, 0.05f, 0.2f, 1f);
153:         final OvershootInterpolator settle = new OvershootInterpolator(2.2f);
154:         a.addUpdateListener(x -> {
155:             float f = (float) x.getAnimatedValue();
156:             pos = from + (i - from) * move.getInterpolation(f);
157:             // ينخفض ثم يصعد: 1 ← (1−dip) في المنتصف ← 1 مع ارتداد في آخر الحركة
158:             float down = (float) Math.sin(Math.PI * Math.min(1f, f / 0.78f));
159:             float base = fromLift + (1f - fromLift) * f;
160:             float l = base - dip * Math.max(0f, down);
161:             if (f > 0.6f) l = Math.min(l, 1f) + (settle.getInterpolation((f - 0.6f) / 0.4f) - (f - 0.6f) / 0.4f) * 0.12f;
162:             lift = l;
163:             invalidate();
164:         });
165:         anim = a;
166:         a.start();
167:     }
