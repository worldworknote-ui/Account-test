15:  * «الرصيد» هنا هو ميزان المكتب: مجموع أرصدته بكل العملات مقوّمًا بالدولار (لنا − علينا)، ويُرتَّب بحجمه المطلق.

17: public final class OfficeOrder {
18:     private OfficeOrder() {}

20:     public static final int ALPHA = 0, BIGGEST = 1, SMALLEST = 2, MOST_USED = 3, LAST_OPENED = 4;
21:     public static final String[] NAMES = {"أبجديًا", "الأكبر رصيدًا", "الأصغر رصيدًا", "الأكثر استخدامًا", "آخر ما فتحته"};

23:     /** ما يلزم للترتيب. أي خريطة ناقصة تُعامل كصفر. */
24:     public static final class Inputs {
25:         /** ميزان المكتب بالدولار (لنا − علينا). */
26:         public Map<Long, BigDecimal> usdNet = new HashMap<>();
27:         /** عدد حركات المكتب في آخر 90 يومًا، ثم مجموع حركاته كلها لفك التساوي. */
28:         public Map<Long, long[]> usage = new HashMap<>();
29:         /** آخر مرة فُتحت فيها صفحة المكتب أو سُجّلت عليه حركة. */
30:         public Map<Long, Long> opened = new HashMap<>();
31:     }

33:     public static int clamp(int mode) { return mode < 0 || mode >= NAMES.length ? ALPHA : mode; }
34: 
35:     public static void sort(List<Model.Office> list, int mode, final Inputs in) {
36:         final int m = clamp(mode);
37:         final Collator col = Collator.getInstance(new Locale("ar"));
38:         Collections.sort(list, new Comparator<Model.Office>() {
39:             @Override public int compare(Model.Office x, Model.Office y) {
40:                 if (x.pinned != y.pinned) return x.pinned ? -1 : 1;
41:                 if (x.active != y.active) return x.active ? -1 : 1;
42:                 int c = 0;
43:                 switch (m) {
44:                     case BIGGEST: c = size(in, y).compareTo(size(in, x)); break;
45:                     case SMALLEST: c = size(in, x).compareTo(size(in, y)); break;
46:                     case MOST_USED: {
47:                         long[] ux = use(in, x), uy = use(in, y);
48:                         c = Long.compare(uy[0], ux[0]);
49:                         if (c == 0) c = Long.compare(uy[1], ux[1]);
50:                         break;
51:                     }
52:                     case LAST_OPENED: c = Long.compare(opened(in, y), opened(in, x)); break;
53:                     default: break;
54:                 }
55:                 return c != 0 ? c : col.compare(Model.nz(x.name), Model.nz(y.name));
56:             }
57:         });
58:     }
59: 
60:     static BigDecimal size(Inputs in, Model.Office o) {
61:         BigDecimal v = in.usdNet.get(o.id);
62:         return v == null ? BigDecimal.ZERO : v.abs();
63:     }
64: 
65:     static long[] use(Inputs in, Model.Office o) {
66:         long[] v = in.usage.get(o.id);
67:         return v == null ? new long[2] : v;
68:     }
69: 
70:     static long opened(Inputs in, Model.Office o) {
71:         Long v = in.opened.get(o.id);
72:         return v == null ? 0 : v;
73:     }

79:     public static Map<Long, Long> parseOpened(String s) {
80:         Map<Long, Long> m = new HashMap<>();
81:         if (s == null) return m;
82:         for (String p : s.split(",")) {
83:             int i = p.indexOf(':');
84:             if (i <= 0) continue;
85:             try {
86:                 long id = Long.parseLong(p.substring(0, i).trim()), t = Long.parseLong(p.substring(i + 1).trim());
87:                 if (!m.containsKey(id)) m.put(id, t);
88:             } catch (NumberFormatException ignored) {
89:                 // جزء فاسد يُهمل
90:             }
91:         }
92:         return m;
93:     }
94: 
95:     public static String touchOpened(String s, long office, long when) {
96:         StringBuilder b = new StringBuilder().append(office).append(':').append(when);
97:         int n = 1;
98:         if (s != null) for (String p : s.split(",")) {
99:             int i = p.indexOf(':');
100:             if (i <= 0 || n >= 400) continue;
101:             if (p.substring(0, i).trim().equals(String.valueOf(office))) continue;
102:             b.append(',').append(p.trim());
103:             n++;
104:         }
105:         return b.toString();
106:     }
