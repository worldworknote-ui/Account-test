1443:     /** الاعتماد: تُكتب القيود الآن بتاريخ الحركة الأصلي، وتصير نشطة. من اقترحها لا يعتمدها. */
1444:     public void approveTx(long id) {
1445:         require(Auth.Perm.APPROVE);
1446:         SQLiteDatabase d = getWritableDatabase();
1447:         d.beginTransaction();
1448:         try {
1449:             Model.Tx t = null;
1450:             try (Cursor c = d.rawQuery("SELECT " + TX_COLS + " FROM tx WHERE id=" + id, null)) {
1451:                 if (c.moveToFirst()) t = readTx(c);
1452:             }
1453:             if (t == null || !t.isPending()) throw new IllegalStateException("الحركة ليست بانتظار الاعتماد");
1454:             Model.User u = SmartApp.currentUser;
1455:             if (u != null && usersEnabled() && enteredBy(t, u)) throw new IllegalStateException("لا يعتمد المستخدم حركة اقترحها بنفسه");
1456:             // 10.5 (AUDIT-018): العملية المترابطة (تبديل عملة أو تحويل بين مكتبين) تُعتمد بساقيها معًا، فلا تنفذ ساق وتبقى الأخرى معلّقة
1457:             List<Model.Tx> legs = new ArrayList<>();
1458:             legs.add(t);
1459:             if (t.isLinked()) {
1460:                 try (Cursor c = d.rawQuery("SELECT " + TX_COLS + " FROM tx WHERE pair_uuid=? AND id<>" + id, new String[]{t.pairUuid})) {
1461:                     while (c.moveToNext()) {
1462:                         Model.Tx o = readTx(c);
1463:                         if (!o.isPending()) throw new IllegalStateException("الساق الأخرى من هذه العملية ليست بانتظار الاعتماد؛ لا تُعتمد ساق واحدة.");
1464:                         legs.add(o);
1465:                     }
1466:                 }
1467:             }
1468:             for (Model.Tx x : legs) {
1469:                 checkLock(d, x.createdAt, "تاريخ الحركة يقع داخل فترة محاسبية مقفلة");
1470:                 // 10.5 (AUDIT-015): المكتب ما زال نشطًا والعملة ما زالت مفعّلة له وقت الاعتماد
1471:                 validate(inputOf(x));
1472:                 // 12.4: الخاصة غير المحسوبة في الرصيد تُعتمد إلى «خاصة» بلا قيود
1473:                 boolean unposted = x.special != null && !x.special.isEmpty() && !x.specialBal;
1474:                 if (!unposted) postTx(d, x.id, inputOf(x));
1475:                 d.execSQL("UPDATE tx SET status='" + (unposted ? Model.STATUS_SPECIAL : "ACTIVE") + "',approved_by=?,approved_at=? WHERE id=" + x.id,
1476:                         new Object[]{u == null || !usersEnabled() ? null : u.id, Clock.now()});
1477:                 audit(d, "APPROVE_TRANSACTION", "tx", x.id, t.realUser() + (legs.size() > 1 ? " — عملية مترابطة (" + legs.size() + " ساق)" : ""));
1478:             }
1479:             d.setTransactionSuccessful();
1480:         } finally {
1481:             d.endTransaction();
1482:         }
1483:     }
